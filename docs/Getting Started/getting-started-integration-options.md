### Como funciona?

A CrediPay foi desenvolvida com uma arquitetura modular, que permite total flexibilidade na forma de operação: da integração nativa com seus sistemas até o uso completo da nossa plataforma web, sem necessidade de código.

Essa modularidade permite que cada empresa escolha o modelo que melhor se adapta à sua operação, com possibilidade de evoluir de forma progressiva — seja para acelerar o go-live, seja para adaptar-se a restrições técnicas internas.
