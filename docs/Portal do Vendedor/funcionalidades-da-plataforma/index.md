Com a CrediPay, você tem o controle de ponta a ponta das suas transações. Ao utilizar a plataforma, você será capaz de:

* Criar Pedidos de Forma Ágil: Inicie transações rapidamente digitando os dados manualmente ou automatize o processo importando o arquivo XML da sua Nota Fiscal (NF-e).
* Validar Crédito em Tempo Real: Verifique automaticamente o CNPJ e o limite de crédito disponível do seu cliente antes mesmo de finalizar a criação do pedido.
* Gerenciar Faturamento Flexível: Envie uma única nota ou anexe múltiplas Notas Fiscais a um mesmo pedido, ideal para operações com entregas fracionadas.
* Automatizar as Cobranças: Esqueça a emissão manual de boletos. Assim que o pedido e as notas são validados, o sistema gera e envia os boletos diretamente para o e-mail do comprador.
* Acompanhar e Gerenciar Recebíveis: Monitore o status das aprovações dos compradores, visualize os boletos gerados e processe reembolsos (parciais ou totais) diretamente pelo seu painel de controle.

Vamos começar?
Navegue pelos menus laterais para acessar o passo a passo detalhado de cada uma dessas funcionalidades, começando pelo nosso guia de **Como adicionar um novo pedido**.
